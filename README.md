## サイト概要
### サイトテーマ  
エンジニアコミュニティサイト

### テーマを選んだ理由  
プログラミングを学んでいるときに、調べてわからないことや不安なことがあったときにプログラミングを勉強している人も関係する全ての人が気軽に相談できる場が欲しいと感じました。
現役エンジニアのコミュニティサイトはありましたが、未経験だったり勉強中の人が気軽に話あえるサイトやアプリはないと感じました。
そこで、勉強中の人も未経験の駆け出しエンジニアも全てのプログラミングに関係する人が気軽に話し合える場があれば、同じように不安に感じている人の役に立てると考えました。
私が実際に感じた不安から同じように感じている人の役に立てればと思いこのテーマにしました。

### ターゲットユーザ  
* エンジニアを目指している人  
* プログラミング勉強中の人
* エンジニア
* プログラミングに関係する全ての人

### 主な利用シーン  
* 勉強中で調べてもわからない時  
* 不安を感じた時
* 情報交換をしたい時

## 開発環境
- OS：Mac
- 言語：HTML,CSS,JavaScript,Ruby,SQL
- フレームワーク：Ruby on Rails
- JSライブラリ：jQuery
